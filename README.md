# DraftAI · 个人 AI 工程制图自动解题与动态作图系统

> **现行唯一产品定位（2026-10-23）**：供学生个人学习使用的 AI 工程制图自动解题与动态作图系统。陌生题图经人工审核条件后由独立数学求解器计算，并通过唯一 V5 逐笔作图；二维/三维共享同一 Geometry 数学结果。不是教师课程网站、固定题库、预制动画播放器或完整 CAD 软件。

## 核心使用流程

**题图输入 → AI 识别候选 → 用户确认/修正 → 数学求解与验证 → 自动构造作图步骤 → V5 动态逐笔绘制。**

1. **导入题图**：未来支持照片、截图、扫描的二维工程图；保留原图坐标、校正和来源信息。
2. **识别条件**：提取点、有限线段、圆、圆弧、R/Φ 尺寸、角度、尺寸线、已知与待求；不确定结果允许直接修改。
3. **真实数学求解**：由几何内核而非语言模型猜测答案；检查单位、数值残差、切触、投影和约束状态，区分唯一解、多解、无解、欠约束与不支持。
4. **自动生成作图步骤**：根据已验证的几何结果生成辅助线、辅助圆、交点、切点、目标轮廓等有依赖关系的 ConstructionStep；不能针对每道题预先手写动画。
5. **动态图工作台**：V5 逐笔绘图、暂停/继续、速度调节、进度拖动、步骤回退、辅助线显示、黑白图纸、线段点选与自动聚焦；修改条件后旧结果和步骤失效，须重算。
6. **结果复核与导出（目标功能）**：区分确认结果与待确认分支，逐步扩展 SVG/PNG 作图及步骤图导出。

**目标覆盖任意来源的二维题图输入，不代表现阶段已经支持求解任意二维工程图。** 对未识别、条件冲突、数学欠约束或不支持的题型，必须明确提示，不生成伪装为标准答案的动画。

## 现行架构及代码门禁（以 #372、#152、#497 为准）

- **唯一计算主线**：人工确认的 ProblemDraft → M0 数值与单位 → M1 几何拓扑/约束结构 → M2 通用残差、分支、局部自由度与证据 → M3 专业解析/构造求解 → 版本化 SolveResult/Geometry Scene → 第一角法 V/H/W 及三维共享呈现 → ConstructionIntent → ConstructionStep DAG → **唯一 V5 时间轴** → M5 独立题图/数学/动画/线上验收。
- **不可一题一开发**：禁止按某道教材题写特判、预制答案、单独求解引擎或动画播放器。点线面、网格、投影、可见性、对象 ID 和修订失效应抽成可复用数学及表示能力；专业算法只提供可核验的几何证据。
- **强制分层边界**：M2 不得反向依赖 M3；可信求解与显示/相机变换隔离；2D/3D 属于一个数学场景的多视图，未证明的遮挡、分支和唯一性必须 fail closed。纯二维题不能凭空制造三维结果。
- **现行提交机制**：以 `main` 为基线，独立分支与 PR、检查 diff、适用数学反例/安全/回归测试、当前 HEAD 五类 CI 全绿且可合并即 squash-merge；不等待 00/09 外部人工批准。Cloudflare 原生构建、Production Active SHA、真实浏览器与 Android 验收分别核实，不把 PR 或 CI 视为上线。
- **规则权威**：[数学及证据 #372](https://github.com/07xh/engineering-drawing-study/issues/372) · [开发/合并/发布 #152](https://github.com/07xh/engineering-drawing-study/issues/152) · [共享 Geometry 与项目工作台 #497](https://github.com/07xh/engineering-drawing-study/issues/497) · [圆锥真实缺口 #504](https://github.com/07xh/engineering-drawing-study/issues/504)。旧版本号、早期 R0–R3 阶段表和历史 Issues 只作历史，不得替代现行规则。

## 当前可用与尚未完成

- **已合并代码（不是完整验收）**：#394–#396 的二维正式意图/V5 主链；#495、#499、#502 的本机协调/存储/确认 API；#503 的受限圆锥截线分类和无交线展示；#505 的共享 Geometry Scene；#506 的极大坐标方向及 mm 单位校验。以上均不是任意工程制图题自动完整解答。
- **目前明确未完成**：真实公共图像审核与本地项目 UI、完整文件导入导出、一个会话下的二维/三维选择及 V5 同步、非椭圆有限圆锥截线、全部虚实线证明、未带答案原题整题盲测、Cloudflare Production Active 与 Android 实机验收。按 #497/#504 修复，不以新框架或演示页面替代。

- **已存在的基础工具**：部分点的三面投影、圆弧连接、几何约束与自由度分析、辅助作图和其他专项实验页面；实际支持的条件应以各工具说明和通过的测试为准。
- **尚不能宣称已完成**：对任意新图片的端到端 AI 自动识别、通用求解、自动作图及完整私人题图上传服务。研发任务或绿色 CI 不等于这些能力已交付。
- **辅助功能**：原有教材与教学研究代码可以作为数学样本或参考，但不构成产品首页、主要使用流程和新增开发的优先级。

## 使用环境与安全边界

优先兼容 Android 平板、手机及桌面浏览器，重视手指/手写笔操作和图纸可读性。

公共站点只发布经过白名单构建的基础工具；未建立完整身份认证、私密对象存储和上传限制之前，不开放私人题图上传，也不在公开 GitHub 仓库或 `dist/` 存放原始教材、个人习题照片或模型密钥。README 的功能目标与目前已部署能力必须明确区分。
