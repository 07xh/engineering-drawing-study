# 图学课堂 · 工程制图与 AutoCAD 第3版教材知识地图

目前独立部署的图学课堂以用户提供的 **《工程制图与 AutoCAD》第3版，胡建生主编，机械工业出版社** 为新的知识体系依据。

## 全新知识体系（本轮重建）

- 用完整的 292 页 PDF **第6页目录** 从零建立 12 章与附录索引：12 章、53 个正文小节、附录 A/B/C。
- **教材页码与 PDF 对照**：印刷正文第1页是 PDF 第7页；正文第 n 页对应 PDF 第 n+6 页。章节从印刷第2、27、54、84、97、122、143、169、187、196、208、225页开始。
- **分级真实性**：`toc-only` 仅说明已按原书目录核验章节名称和页码；`page-reviewed` 表示对照相应教材正文图文后编写了原创学习讲解。前者不填写猜测的规律、作图步骤或自由度。
- 本批将原来依据 23 页局部扫描自行归纳的 **31 张知识卡全部从 `knowledge/knowledge-data.js` 替换**，不再展示旧 ID。新库含 56 个目录条目（53节+3附录）和第二章 16 个已复核、重新撰写的知识讲解。
- 各知识点可按**章节、小节、内容状态、学习情况**检索；只针对已复核的讲解提供阅读标记。旧知识卡的浏览器进度键保留但不继承，避免误认为已学习新版内容。
- 第二章部分已校验专题继续使用**原创三视图动态模型**和代表点的线性自由度演示；不相关章节和未复核章节不套用默认空间点模型。

## 旧版项目与数据的边界

- 首页原有的 **10 个原创投影练习专题、74 道原创训练题**属于独立练习系统，**不是新教材的官方题库，也不是逐章核对的知识库**。为防止意外丢失练习、记录及学生作图，本轮不删除独立练习系统代码；新教材知识页不再继承旧知识卡的正文或题目映射。
- 旧 28 道 2-6～2-9 局部描图作业目前仍为 `partial`，其图源、点位、尺寸、原书题号和投影关系尚未完成与本次教材的确认。因此不能宣称它们就是这本书的原题，也不能开放未经审核的答案。
- 所有自由度分析都是针对描述清楚的几何模型和特定约束条件，不意味着整张教材题的唯一性已经经过验证。
- `knowledge/solution-gate.js` 与 `labs/verified-solutions.js` 继续执行答案准入；本轮重建没有开启任何原题答案。

## 教材私密与公开版本分离

PDF 由老师用于课程学习提供。**未经明确许可不在公开 GitHub 仓库、静态网站目录、Pages 构建产物中发布教材原 PDF、整页扫描图或出版社原版答案。**

当前公开 GitHub 只保存：原书章节标题/页码索引、重新撰写的学习讲解、原创数学/几何演示、功能和测试代码。未来如需将原图完整复刻与专属答案动画放到私人教材区，必须先建立真正的身份认证和非公开文件存储；“隐藏链接”不等于访问保护。

## 开发与测试

- `knowledge/knowledge-data.js`：当前新版索引与已核实的讲解内容。
- `knowledge/knowledge-app.js`：章节/小节筛选、核实状态与阅读记录。
- `knowledge/visual-model.js`：只为具体已核实的第二章主题提供原创投影模型。
- `scripts/check-knowledge.cjs`：12章 / 53小节 / 3附录 / 16讲解 / 页码来源与旧知识移除断言。
- `scripts/check-visual-research.cjs`：动态几何、原题隔离、检索和答案准入检查。
- `scripts/build-static.cjs`：按白名单发布公开网站资源。

部署源：`07xh/engineering-drawing-study`，默认分支 `main`，公开网站的实际更新取决于 Cloudflare Pages 部署是否成功。
