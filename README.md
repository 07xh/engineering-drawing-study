# 图学课堂 · 胡建生《工程制图与 AutoCAD》第3版

**当前唯一课程体系**：用户提供的292页《工程制图与 AutoCAD》第3版。网站采用新版12章、53节、3个附录的教材目录。第一章20条、第二章16条、第三章18条已建立重新撰写的知识讲解，其他章节仍标明“仅目录索引”。

## 教材原有例题动态化（本轮新增）

- 第一章**例1-1，印刷第13页 / PDF第19页，图1-22**：直线AB七等分，逐帧按照原书使用等距辅助射线、连接最后分点、平行线交会及等距核验。
- 第二章**例2-2，印刷第34页 / PDF第40页，图2-14**：由同一空间点的正面/水平投影求第三面投影，逐帧完成等高联系与45°深度转移，并用坐标一致性验算。
- 例题直接插入对应知识点页面，包含课本来源、五帧步骤、为什么这样做、自由度分析和最终几何验证；同一知识点不再同时展示旧通用动画冒充课本步骤。
- **不新增原创例题**。旧讲义中的自拟“概念演示”暂时隐藏，逐节用经原书确认的教材例题替换。
- 当前仍未实现教材扫描原图逐像素复刻，SVG所用线长和点位按绘制需要归一化；原书解题的关系和顺序经过页图核对。不要把演示画布上的数值当成出版社题图尺寸。
- 来源登记：`docs/textbook-worked-examples-audit.md`。当前网站私密化仍未完成，因此不发布原书页图或完整PDF。

- **删除旧版第二章课程**：旧 `labs/v7.html`、`lessons/plane-projection.html`、`labs/line-projection.html` 与相应脚本等已从当前分支删除。旧版 HTML 和 CSS 不再打包。
- **保留新版教材第二章**：`knowledge/index.html` 中的第二章16条知识讲解仍在；对应的点投影、三面关系及自由度教学工具可以继续作为知识解释使用，但不提供自编测试题。
- **保留已提交习题**：`labs/verified-exercises.js` 中的28条 2-6～2-9 部分描图记录与笔迹操作机制仍保留。资料与新上传第3版完整PDF之间的题号、原图、尺寸与投影对应尚未全部完成审核，状态继续为 `partial`。题目首页不再给它们配未经原书核实的模拟题干，也不开放未经验证的标准答案线。
- **教材原题**：必须先用用户上传的实际页图核对已知线、尺寸、点名、图号和题意；验证之前不能把网络通用例题或开发示意充当原题。

## 新版教材知识详讲

原有54条各含概念、规律、作图步骤、约束理解和易错点。新增 `knowledge/lesson-depth.js`，目前对其中28个重点条目加入**更长的章节精讲**：讲前疑问、逐层推导、各步骤为什么成立、自由度解释、概念演示（不是题库习题）、结果检查和适用范围。

- 第一章：比例、尺寸与基准、线段等分、圆弧连接、已知/中间/连接弧等；
- 第二章：三视图三等规律、两投影求第三面、特殊直线、面内辅助线、圆锥取点；
- 第三章：表面连接关系、棱柱截交线、两圆柱相贯、组合体定位尺寸和读图歧义。

**范围透明**：这28条新增精讲不表示其他26条已达到相同详尽程度；后续按原书逐页继续补充。没有完成原图核对的习题依然不会得到推测的答案动画。

## 版权与隐私保护

用户的PDF由老师作为课程学习资料提供，公开仓库不上传整本教材、扫描页或出版社标准答案。完整原书题图及其专属答案动画以后应在具有**真正身份认证和私密文件存储**的区域使用，而不能依靠前端隐藏链接。

当前 GitHub 公开源代码与 Cloudflare 发布产物仍是不同概念。旧文件从本轮分支删除，Git 历史保留回退能力；Cloudflare Pages 是否已发布最新合并提交，必须实际验证。
