# DraftAI · 个人 AI 工程制图自动解题与动态作图系统

> **现行产品定位（2026-10-23）**：为个人学习新工程制图题而设计。不是教师授课网站、固定教材题库、预制动画合集或通用 CAD。**唯一有效规范索引：[docs/CURRENT-RULES.md](docs/CURRENT-RULES.md)**；旧 Issue/历史计划不能覆盖现行规则。

## 主要使用流程

**题图导入 → 识图候选 → 人工审核/改条件 → M0–M3 可信几何求解 → 唯一 SolveResult → ConstructionIntent → ConstructionStep DAG → 单一 V5 逐笔动态作图 → 验证/导出。**

- **AI 提供候选，不提供数学事实**：图片中的点线面、圆弧、尺寸/单位、已知条件都需要可追溯来源；不确定或冲突时让用户确认，不能把候选直接当已确认条件。
- **数学与证据唯一**：复用 M0–M5、已有求解器与第一角法 V/H/W 投影规则；区分 unique / multiple / underdetermined / none / unsupported、局部自由度和全局唯一性。
- **二维与三维联动**：空间题从同一个几何解和稳定实体 ID 投影二维 V/H/W、驱动可旋转三维证据视图；不能分别求解、改变标准视图位置或让镜头影响数学状态。纯二维题不虚构三维。
- **真实逐笔动画**：一个 ConstructionIntent → ConstructionStep DAG → V5 时间轴；辅助线、虚实线、曲线连续性、速度、回退、点选、黑白、聚焦须服从已验证的步骤和显示证据。
- **一个本机项目**：题图/确认条件/二维图纸/三维证据/版本化数学结果共享同一项目上下文；图像及项目默认本机保存。更改条件、校准或来源使旧解与步骤失效，恢复后须重新核验。
- **保留高级工具**：旧 URL 和未迁移的已验证工具不因新导航而消失；迁移完成、引用与测试核验后才清理过时代码。

目标是处理任意来源的新二维题图，**不是当前已能正确解答任何二维图、任何截交线或全部教材习题**。对未知/无解/多解/条件不足和不支持的情况必须明确显示，而非造出伪标准答案。

## 当前交付边界

现有部分几何/投影/截切工具可单独使用，但精确支持范围以各页面及最新回归为准。统一项目 API 与本机数据层已有增量合并；完整图像审核页面、跨设备实机及陌生题端到端签收必须逐项核实，不能因为 API 存在就标为已完成。

开发和发布严格区分 **代码提交、最新 HEAD CI、PR 合并、Cloudflare 生产 Active SHA、真实浏览器/Android 使用验收**。README 不是实时进度面板。
