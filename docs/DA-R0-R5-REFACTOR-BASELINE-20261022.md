> 2026-10-22 审计快照；基线 main `d4eac3a49c484b595914a56605b83b279a56ccbe`。此文档不是实时仪表盘。重读仓库 HEAD、PR 和 CI 后再更新状态。

## 项目定位

DraftAI 是**数学驱动的工程制图智能解题与交互教学平台**。真实几何输入 → 约束/自由度 → 全部合格分支 → 数学求解和证明链 → 同纸 V/H/W、平面图纸和可选三维 → 全面教学/提示/自主作图 → 数学判题。AI 只能提取、解释、核查条件，不能编造未经验证的几何标准答案。P0 严守原定 0–3 阶段；鸿蒙、通用 CAD、规模化 AI/课程导入不进入本轮。

## R1 的兼容策略与本 PR 的真实范围

本 PR 新增只读 `workbench/verified-teaching-plan.cjs`，直接调用已经测试的数学求解器：

- `adaptPointProjection(input,{revision})`：保留模型解的 mm 单位，但明确投影步骤是 **sheet-px**，不将投影显示坐标伪装成新的三维求解约束。
- `adaptDirectedFillet('circles'|'segments',input,{revision})`：使用真实候选分支、G1 与相切残差，仅对 `selected + G1` 的结果输出一条可播放的圆弧链，保持 **model-mm** 和数学 `cw/ccw`，绝不交给旧 SVG 弧度假定直接绘制。
- 无解/欠约束、没有明确分支/方向/源轮廓走向，以及没有真实证明的状态均不输出标准解步骤；`readiness` 与真实 `result.status` 分开存储，避免把“选中一个分支”冒充全局唯一。
- 稳定步骤 ID、依赖和动作 ID 验证；禁止悬空前置、动作 ID 重复。没有改 `core/**`、`engines/**`、现有页面、CI、Cloudflare 配置、课程或公开资源。
- 新适配协议是 **`draftai-teaching-plan/0.1` 仅供只读消费者**，不是宣称已经冻结 `DA-GEOM-CONTRACT-v1.0`，也不是完整已发布工作台。

## 最优后续开发顺序与可并行边界

1. **R0/R1 本 PR**：审计快照、跨两类真实求解器的证明链适配、反例测试。
2. **R1-B（01+07）**：签收数学模型到图纸坐标/圆弧方向的显式变换，定义兼容动作验证器与统一可追溯图元 ID；先验收，再冻结。
3. **R2-A（07）**：评估草稿 #174、#178、#179，复用 V5 确定性时间轴可能成立的模块，合并为唯一播放器状态管理（只改 `workbench/**`）。不可将纯时间轴测试当作正式画面交付。
4. **R2-B（03+07）**：先在正式点投影界面使用适配计划完成同纸 V/H/W、45°步进、3 模式、旧态失效及真实数学判题；提供可回退改动。
5. **R2-C（02+07）**：复用同一播放器接入两圆/线圆/两线段，必须校验候选选择、有限边界、cw/ccw 与 G1；不直接删原教学入口。
6. **R3（02+03+07）**：在两类 MVP 上补最小数字尺规（平行线、垂线、圆规、交点吸附、分支选择）、证明关联和可靠范围内的自由度说明；与自由手绘双轨共存。
7. **R4-P0 最小整合（00+07）**：统一教学导航，保留旧 URL 与课程数据，接入自由建模器 ID/显示兼容性，不要求 P0 完成任意形体约束或整本教材转换。
8. **R5（09 全程 + 00 最终）**：每 PR 同步数学/界面/隐私测试；最后正式完成安卓平板触笔、响应式、正式生产 worker active SHA、公开/私有资产隔离及原任务书 P0 0–3 验收。

**并行原则**：01 核心契约适配、02 平面数学边界、03 投影/DOF 数学样本、07 独立播放器、09 测试审计可以并行；同一个公共 contract 和发布文件只能经 00 串行集成。不要增添鸿蒙项目、第二套发布控制器或大型三维布尔内核。所有 PR 必须有 HEAD SHA、测试数值、文件范围、问题/回退方法；构建成功≠生产域名已验证。

## R0–R5 阶段签收门槛

- **R0**：模块责任、保留/适配/淘汰清单和回归风险确立。
- **R1**：统一数据对真实点投影、两圆和有限两线段的有效/无效输入均表现正确；合同不虚假冻结。
- **R2**：真实两条 MVP 在一个可回退的 UI 控制层复用同一套三模式、步骤、分支与画纸显示；绘图动画只是消费证明链。
- **R3**：P0 两类 MVP 的关键学生数学尺规步骤可自行构造、吸附和判题，不复制正确答案。
- **R4**：统一导航、入口兼容、旧课程/私人资源不泄露；深度建模升级延后。
- **R5**：数学、界面、权限、设备及生产证据全部齐全，00 在 Issue #143 明确签收。
