# DraftAI · R5 生产资源核验操作与证据边界

> 此项是辅助 R5 验收的**独立、只读**生产核验工具，不是发布器。不会触发部署、回滚或修改 Cloudflare 设置。

## 为什么需要独立检查

GitHub CI 和 Cloudflare Workers Builds 成功，不等于 **drawing.0701000.xyz 正在服务对应的最终资源**。一个生产域名可能仍在提供旧 bundle、拒绝访问，或意外公开了打包前的内部测试和源码。应用内的三面投影、圆弧与学生笔迹也可能在某个真实浏览器上存在兼容问题。

## 一次性执行方法

从对应的 **已合并 main 提交** 克隆/更新工程，在构建依赖安装完成后运行：

```sh
npm install --no-package-lock --no-audit --no-fund
node scripts/build-static.cjs
node scripts/verify-production-learning-site.cjs --base-url https://drawing.0701000.xyz --dist dist --json
```

其中 `--base-url` 必须**显式指定**。工具无任何默认生产环境、权限令牌或可修改操作。

自动比较五项真实公开页面/入口产物：`index.html`、点投影/圆弧页面 HTML 和它们由 esbuild 生成的 bundle。比较在线下载字节和本地当前构建字节的 SHA-256，而不是只检查 HTTP 200。还检查六个不应公网直出的源码、测试及教材审计路径，要求返回 401/403/404/410；若返回 200，报告风险并核查是否为伪 404 页面。

## 状态、退出码及限制

| 状态 | 退出码 | 正确解释 |
|---|---:|---|
| `pass` | 0 | **五项**线上资源字节与此本地构建一致，所查 **六项**非公开路径未直接返回 200。证据限于这些具体 URL 和执行时刻 |
| `fail` | 1 | 至少存在资源 hash 不一致、公开入口错误状态、内部路径 HTTP 200 或本地私密文件进入 dist；可能是旧部署、CDN 内容改写或软 404，必须进一步判断 |
| `unverified` | 2 | 网络失败、HTTP 5xx、缺少本地构建、远端无法给出结论；**不等于验证成功或发生泄露** |

无论 `pass` 与否，该检查都**不能**证明 Cloudflare 控制台 Active Deployment 的真实 SHA，不能证明安卓触笔、真实浏览器事件、三种模式全套数学步骤，也不能检查所有尚未知晓的敏感路径。

## 真实设备/生产 R5 仍需另外验收

- 在生产域名打开点投影与圆弧教学页，确认版本、输入和报错状态（保留实际访问日期、设备浏览器版本）。
- 安卓触笔或鼠标真实验证：画辅助线、尺规辅助圆、手动选择圆心、标注两个切点、画有向圆弧；撤销、重做、改题失效；不能将浏览器 VM 模拟等同为实物验证。
- 核实 V/H/W 同纸、45°、候选分支、G1 有向方向和动态绘图步骤的实测表现。
- Cloudflare 控制台确认实际生产 deployment ID/SHA、自动构建分支及失败回滚方式；未经授权不修改生产配置。
- 将证据记到 00 总控 #143 与 09 专项 #153；缺少证据则 `待验收`，不能在 PR 中宣称 R5 全部完成。

## 安全与回归

单元测试 `tests/workbench/r5-production-learning-site.test.cjs` 仅使用本地随机端口 HTTP 伪生产服务验证状态机，不访问用户个人账号、第三方源或真实 Cloudflare 生产域名。常规 `workbench` CI 会自动运行这些测试。工具默认只接受 HTTPS 站点，只有测试时显式指定 `allowHttpLoopback` 才允许本地 HTTP。时间、字节限制防止请求无限等待或意外大文件加载。
