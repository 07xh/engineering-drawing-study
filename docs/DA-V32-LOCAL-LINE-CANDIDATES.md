# DraftAI 08 V3.2｜纯本地二维直线候选检测（初步）

本增量为 #234 的图元识别前置研究，连接上一批人工来源确认 PR #254；总控 #240、09 审核 #243。

## 完成的范围

`recognition/local-line-candidates.cjs` 提供真正可执行的轻量二维栅格直线检测：
- 输入为**限制在 24–900 像素单边的 RGBA 帧**，本地计算全局阈值和二值图；
- 在受限 Hough 投票空间中估计直线方向与位置，寻找黑色笔画上连续支持点的**有限线段候选**；
- 过滤明显的黑底、大面积噪声和短碎线，对候选做方向/位置去重；
- 输出候选 `image-px` 起终点、像素 bbox、方法标识和启发式分数，**从不输出毫米约束或数学求解证明**。

`labs/local-line-candidates-ui.cjs` 使用浏览器 2D Canvas，在用户按“检测直线候选（实验）”时读取**当前浏览器内显示的原题图片**，先下采样最大边到 640px，再把候选映射回原图像素尺寸，叠加为紫色虚线。只在点击按钮时执行，尺寸与候选数量均有限制，不上传或持久化图像。更换/清除图片时清除候选图层。

## 不足和后续前置条件

**这不是视觉大模型，也没有 OCR。** 本初步算法主要适合清晰黑白线稿，照片透视、纸张阴影、文本密集、复杂弧线和断线等均可能误判或漏检；不判断虚实线、切点、半径、圆、圆弧、三视图意义。像素图元没有真实毫米单位，也可能与文本边框混淆。

必须在经过人类确认的图形与尺寸识别、像素到模型变换（或从标准工程尺寸单独构建几何约束）、数值尺度/拓扑验算后，才能调用真实 01/02 数学求解。**不能将检测到的紫色线直接送入 SolveResult。**
