# DraftAI 08 V3.2｜原图来源框选与逐项条件确认

关联总纲 #233、00 Gate A/B #240、08 专项 #234、07 工作台 #236、09 审核 #243。

## 当前交付

在 `labs/auto-fillet-live.html` 的本地原题图片预览中提供**可选“图片条件逐项核对（严格模式）”**：

1. 选择 JPG/PNG/WebP 原题照片，仅在浏览器本地显示；`local-problem-preview.cjs` 继续负责 Blob URL 生命周期，不发生远程上传。
2. 开启严格模式，选择“连接半径”“圆一半径”“线段起点 X”等必需字段，在**原图上拖拽框选**这个值对应的图形/标注。使用原图固有宽高定义 bbox，适配浏览器缩放和高图滚动。
3. 点击**确认当前数值与框选区域相符**，将 UI 此刻的有限毫米值和本地 `sourceId` 联系起来；每个必需字段都必须有一个有效的标注、确认值和原图 bbox。
4. 最后点击**确认全部条件并解题**。此时调用既有 `prepareConfirmedFillet`，生成有原图 bbox/来源记录的 `ProblemDraft`，再经 01 typed math、02 真几何解算器和 07 V5。
5. 任何字段编辑都会撤销该字段和最终确认；更换照片、切换题型也清空原图来源关联；未确认的严格模式**不调用已验证答案的 V5 动画**。关闭严格模式则保留原先的直接手动确认几何输入方式。

## 不是“AI 自动识图”

**本次没有调用 AI/OCR，也不能自动读取图中数字。** 人需要选择哪一个字段、拖出来源区域、填写毫米值并分别确认。相应 bbox 对象设置 `confidence:0` 表示没有模型推理置信度；绝不能宣传为 100% 识别准确率。数学证明只能由几何内核完成，而不是 UI 或标注框决定。

当前已支持三类：两有限线段、线段+整圆、两个整圆的圆弧连接。其他复杂二维轮廓、来源圆弧区间、空间斜截面、相贯线继续按计划扩展。

## 设计边界

- `recognition/image-field-review.cjs`：DOM-free 事务状态模型，保存无图像字节的原图尺寸、每个字段来源 bbox、原始数值核对与最终接受；类型/图像边界沿用 `sourceIndex`。
- `labs/image-field-review-ui.cjs`：与本地图片、移动端指针拖拽、字段数值事件、确认按钮连接，图形只作为本地 SVG overlay；输出不包含任何上传行为。
- `labs/auto-fillet-live-entry.cjs`：严格模式仅在字段全部复核后从受控适配器取得输入，否则调用 `session.replace(null)`，清除旧 V5；其他用户无须开启该模式。
- 只用 `textContent` 更新用户内容，不执行来自图像或 OCR 的代码/HTML。
- 外部客户端若将来引入 AI 识图候选，必须单独处理其可信度、原图变换和来源位置；**本次 UI 最终接受仅由本地点击产生，仍不构成远程用户认证或数学正确性证明。**
