# DraftAI 08 V3.3｜原题图片本地圆与圆弧候选（实验）

本功能位于 DraftAI 的个人自动解题路线图 #233 / #234 / #240 下，是从“能找直线”走向“能检测部分曲线”的独立增量，不涉及课程教学。

## 实际能力

- `recognition/local-curve-candidates.cjs`：输入严格有界 RGBA 帧，计算自适应灰度阈值，提取黑色连通笔画，以代数最小二乘拟合圆心半径，并按角度覆盖、径向 RMS、最小半径与退化矩阵筛选。
- 闭合轮廓产生 `kind:circle`；部分轮廓产生 `kind:arc`（包含像素中心、半径、覆盖角、起止角和 `cw-screen` 图像方向）。
- `labs/local-curve-candidates-ui.cjs`：用户主动点击按钮后本地读取当前照片 Canvas（最大分析边 640px），仅在本地图层标出待核对整圆（蓝色虚线）与部分圆弧（紫色虚线），清除、更换图片时移除候选。
- 单张图像不得绕过 `recognition/image-field-review.cjs` 的字段确认，也不会直接填写工程毫米数、判断几何唯一性或自动生成验证动画。

## 限制与误差

连通域拟合主要适合清晰的白底细线工程图。若曲线与直线相交、轮廓有断笔或文字覆盖、严重透视畸变、扫描阴影、椭圆及文字圆圈等，可能漏检/误检。检测出来的弧只使用**图像坐标方向**，不是工程零件的连接弧 G1 证明。候选的 `confidence` 只是非校准的显示排序数值，不是成功概率。

即使图中半径像素可测，真实尺寸仍需题目明确的 R/Φ 标注或经用户核验的比例标定。不得将候选像素直接解释为毫米条件；斜截面和相贯线不能以此拟合代替三维求交。

## 验收与后续

`node --test tests/workbench/v33-local-curve-candidates.test.cjs` 测试封闭圆、部分圆弧、双圆、直线误报、空白与恶意图像边界，确认无上传与数学证明越界。完成整个最新 HEAD GitHub CI 后才考虑合并；后续应推进实际尺寸 R/Φ 标注 OCR 与关联、可交互的候选确认、真实摄像照片样本的误报率评估。
