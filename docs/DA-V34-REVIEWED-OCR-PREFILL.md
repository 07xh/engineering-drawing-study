# DraftAI 08 V3.4｜OCR 建议半径预填（明确用户操作）

本增量延续 #265 原生可选 TextDetector 和 #266 OCR 候选 UI，改进浏览器内填写几何条件的交互，同时**保留既有人工核对和数学证明链**。

## 操作
1. 本地打开原题，点击实验性 OCR 按钮。如果浏览器支持 TextDetector，会获得原图尺寸文字候选（例如 R8、Φ20）。不支持则维持纯手动模式。
2. 开启严格核对模式，选择半径字段（`filletRadius`、`r1` 或 `r2`），选择 OCR 文本。
3. 对文字没有明确 mm 单位的情况，必须勾选“我已核对原图尺寸标注的单位为毫米”。
4. 点击“使用所选 OCR 建议半径预填当前字段”。只有符合 R/Φ 严格语法、数值一致且有原图来源框的候选可被处理，直径提议会转换为待核对半径（Φ20→10）。
5. 预填会通过现有数值输入事件立即**撤销旧模型答案/动画**，且该字段仍处于`未确认`；必须再点“确认当前数值”与“确认全部条件”，并选择数学合法分支/有向 G1 之后才能继续 V5 动画。

## 安全范围
- 不会从任意 OCR 数字推断毫米坐标/几何中心；半径字段专用。
- OCR 建议不等于真实尺寸；可以人为修改，用户必须复核原题。
- 无 OCR 时不猜测；`M20`、`O20`、公差文字、任意 HTML 及未确认单位不能直接预填。
- 本地处理，无外部上传、服务端密钥及持久存储；不修改数学求解器和正式发布配置。

## 回归验收
`tests/workbench/v34-ocr-explicit-radius-prefill.test.cjs`（纯函数）及 `tests/workbench/v34-local-native-ocr-ui.test.cjs`（用户点击流程、单位确认、禁填坐标、换图作废）。完成全部 exact HEAD CI 后才能进入 main。

不代表 Android 设备上必然支持 TextDetector，也不代表任意图纸自动 OCR 解题。
