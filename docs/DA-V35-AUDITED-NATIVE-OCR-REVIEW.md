# DraftAI V3.5 / 08-C5 · audited local OCR R/Φ to current math fields

This additive change **extends** the already merged #266 browser-native R/Φ OCR review UI. It does NOT implement a second OCR, mathematical solver, drawing player or upload endpoint. The original image remains browser-local, using the optional existing TextDetector (#265) and strict R/Φ parser (#261).

The original "associate OCR position" control is still **bbox/provenance only**, not confirmation of the mm value. For a stronger path the existing workbench now displays a user-editable OCR label measurement (mm, *Φ entered as diameter*), an independent approval checkbox and "核验本条尺寸并确认当前字段" button. These controls call the previously merged #263 `stageReviewedImageDimension` through the existing #254/#259 `attachImageFieldReview.confirmNotation`, which uses the **current source field** and unchanged model-mm input, NOT a value copied from OCR. R must match model radius; Φ diameter/2 must match source radius, and Φ is forbidden as target fillet R. Label corrections are explicit. The current source bbox is recorded in original image pixels; where the native candidate id is the known `ocr_N` format it is kept as untrusted provenance metadata.

The chosen source field and revised text value must be checked by a person. OCR confidence, image proximity, model-mm calibration and globally unique geometry are *not* proven. This reviews **only one** field. The original strict `acceptSources` requires all other fields and an independent final acceptance before invoking the existing math/verified G1/V5 session. Edits force that acceptance to be renewed.

The OCR select, corrected value and approval are cleared on a new photo, OCR run, unsupported detection or changed selected token. Candidate-field switches or edited numerical text revoke approval. Old in-flight OCR detections cannot replace candidates from a new photo. No external scripts, raw SVG/HTML insertion, fetch, storage, upload, credentials or altered core math/CI/deployment.

**Files**: minimal edits to `labs/local-native-ocr-ui.cjs`, `labs/image-field-review-ui.cjs`, `labs/auto-fillet-live-entry.cjs`, `labs/auto-fillet-live.html`; new `tests/workbench/v35-audited-native-ocr-review.test.cjs` and this document. Tests exercise corrected OCR R12→R10, eventual all-fields approval→real math/G1/V5, wrong Φ target, mismatching radius, stale photo async result, unsupported browser, and local privacy. Exact-head math/planar/projection/workbench/validate + Workers preview required before merge.

**Not solved**: full raster text recognition on browsers without TextDetector; automatic image geometric interpretation or metric calibration; three genuinely unfamiliar photographed engineering drawings processed from pixels to verified animated answer; Android hardware testing; Cloudflare production Active SHA checks. Provenance review is not independent OCR verification.
