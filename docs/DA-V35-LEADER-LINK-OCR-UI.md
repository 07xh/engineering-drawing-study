# DraftAI V3.5 08｜R/Φ OCR 标注的引出线候选在工作台显示

前置：#271 已合并，引入原图像素端点和候选有限引出线关联引擎；#269 并行 OCR 数值核对现已进入主分支。

## 用户工作流

在 `labs/auto-fillet-live.html`：
1. 本地打开照片，按「检测直线候选」和「检测圆与圆弧」。
2. 浏览器支持原生 TextDetector 时，按「识别 R/Φ 文字」，选中 OCR 候选。
3. 工作台首先展示一端靠近文字、另一端靠近曲线轮廓 bbox 的**引出线关联建议**，例如 `line_1 → curve_2，端点误差 4px`；同时保留原本的最近区域备选圆弧列表。
4. 更换或清空直线/圆候选列表会重新计算正在查看的 OCR 关联提示，不继续显示被清除图形的旧证据。
5. 提示仅用于定位和人工核对；绝不自动选择唯一几何候选、修改 R/Φ 尺寸、确认数学证明或解除 V5 的最终确认要求。

## 诚实边界
端点/包围盒可能错误，尤其是重叠轮廓、折线引出、箭头不清晰或文字粘连；**没有箭头尖端检测**，且图形只有像素坐标并无可靠毫米标定。所有结果都应标注未验证，不应用 `globallyUnique`。

对环境不支持 TextDetector 的情况仍用手工数学条件输入，不以其他网络端点自动兜底，也不上传私人图片。
