# DA-08 V3.5: explicit line side for raster segment-circle fillets

Reason for this correction: Hough detection returns finite segment endpoints in an **unstable order** (left-to-right or right-to-left). The existing #277 raster import adapter passed `{side:1}` unconditionally to the true 02 external segment-circle fillet solver. The signed offset normal depends on the **ordered** segment direction. A separate line and circle on the opposing normal may be solvable but previously received a false `none` result.

**New gate:** `prepareReviewedRasterImport` now **requires** an explicit `lineSide` value of `+1` or `-1` for `segment-circle`; no guessed fallback. The public raster editor shows the two options with normal `(-dy,dx)` relative to the *corrected* start→end pixel endpoints, and revokes approval when changed. The selected signed choice is carried by the raster adapter as `lineSide`, mirrored in the active public `circleSide` selector, passed through the backward-compatible `buildConfirmedInput(...,{side})` contract, and forwarded to the proven 02 solver as `options.side`. Legacy manual input still defaults to +1; no analytic solver changes. All other R0 types forbid stray line-side arguments. Wrong / missing side cannot be passed as a verified answer.

New test checks reverse endpoint orientation with reversed selected signed side yields **the same actual candidate geometry** (via the existing real solver), and that missing / invalid values fail closed. Existing segment-circle vector/SVG paths retain their previous explicitly configured behavior; only the new raster editor gets this correction.

Scope: `labs/auto-fillet-form.cjs`, `labs/local-raster-fillet-import.cjs`, `labs/local-raster-geometry-review-ui.cjs`, `labs/auto-fillet-live-entry.cjs`, `labs/auto-fillet-live.html`, `tests/workbench/v35-raster-geometry-metric-review.test.cjs`, this document. No math engine, upload, OCR, V5 timeline, auth, CI workflow or deployment settings changed. Requires exact-head workbench, math, planar, point projection, validate and Workers Preview success before merge. Rollback by reverting one squash commit.
