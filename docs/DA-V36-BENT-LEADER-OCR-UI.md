# DraftAI V3.6｜两段折线引线证据在 OCR 核对面板中显示

依赖已合并的 #278 检测模块与 #273 单段 OCR 引线核对 UI。

在本地二维解题工作台中，用户选择 R/Φ OCR 候选后可同时看到三类互补但**均未验证**的几何定位线索：两段折线 `line_1 → line_2 → curve_1`、单条有限线段 `line_3 → curve_2`、仅根据 bbox 邻近程度提供的候选圆弧。

两段折线显示其两个候选 ID、目标曲线候选 ID、文字端点+折点+曲线终点的总像素误差及转角。只有检测到有效折点与转角才展示；没有则显示“未找到符合条件的两段引线”，不声称图中绝无折线。

在本地重新检测、清空候选线或圆时，当前 OCR 关联提示立即重新计算，避免旧来源与新照片/新的候选列表混用。候选**不得直接选择数学求解器的唯一解、毫米条件或箭头是否有效**。仍需用户按 #269 的 OCR 数值审计流程逐项确认，数学与 V5 另行验证。

测试：在现有 `v34-local-native-ocr-ui.test.cjs` 中添加两段折线模拟图、总端点误差、清空候选后的提示失效，以及未自动接受字段的断言。应用全部数学、平面、投影、工作台、网站构建 CI。Cloudflare 正式域名与安卓实机尚未单独验证。
