# DraftAI V3.8｜浏览器本地照片识图验收工作台

## 新入口

`/labs/recognition-qa.html`（静态前端）：可以用自己制作或获得使用授权的 JPG、PNG、WebP 工程制图照片进行**真实本地识别误差评测**。自动读取图片的是用户当前浏览器，不涉及服务器上传。

操作：选中本地图片 → 点击「运行本地识别」→ 紫色虚线显示当前 Hough 直线和连通域圆/圆弧候选 → 用手指/鼠标在原图上绘制绿色人工真值 → 查看分类 TP/FP/FN、Precision、Recall 和 F1 → **主动选择**导出不包含原照片的 JSON 指标报告。

手工标注工具：
- **有限直线**：拖动两端点（原图像素）。
- **圆**：从圆心拖到圆周。
- **圆弧**：从圆心拖到圆周，另填人工估计的覆盖角。这里没有起止角标注，评价只对圆心、半径和覆盖角。
- **尺寸文字**：拖拽 OCR 文本区域并输入人眼看到的 R12 / Φ20 等文字。由于本页面暂未调用 TextDetector，文字真值不会产生 OCR 命中，可能显示漏检，这是诚实的评测结果。
- **箭头尖端**：点选其图像像素位置。当前本页只运行直线和曲线检测，不运行箭头检测器，因此箭头类同样可能显示漏检，不能据此判断箭头算法的真实性能。

### 指标注意

标注之前显示「需要人工标注」，**不会把全空真值当作 100% 准确率**。任何图片变更、重新检测、图片错误、页面刷新、点击清空，都会废弃旧候选、人工标注与报告。报告中的精确率/召回率是**此张图的人手标注对比**，不是独立审核后的统计模型准确率，也不是工程毫米/G1 标准答案。

### 隐私和构建

- 图片格式仅 JPG、PNG、WebP；单张最大 15 MB。Canvas 分析图最长边不超过 640 像素，真实坐标映射到图片固有尺寸；遇到比例严重变化、过大或解码失败会拒绝。
- 访问过程不产生图片上传、跨域 OCR、localStorage 或持久服务器记录。浏览器使用对象 URL 显示图片，更换图片及关闭页时撤销其 URL。
- 仅在人手点击「导出」时，生成不含 RGBA、图片 Blob、原文件名的 JSON，只保留有限坐标、图元 ID、误检/漏检列表、指标及信任边界声明。
- 新页面和经过 esbuild 打包的 `recognition-qa-bundle.js` 进入静态站点显式白名单（不发布源代码、测试、用户照片、私有文档），主二维解题工作台增加可访问入口。
- 未修改生产环境配置、数学求解和个人上传图库。
