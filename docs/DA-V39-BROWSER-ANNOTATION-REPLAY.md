# DraftAI V3.9｜本地工程题图的复测基准导入与导出

新增页面入口仍为 `/labs/recognition-qa.html`。

## 实际用法

1. 在自己的设备上选择有权使用的 JPG/PNG/WebP 题图，点击「运行本地识别」。
2. 在原图上用鼠标或手指标注直线、圆、弧、尺寸文字框或箭头。标注应涵盖所评测类别的全部对象，防止漏标造成虚假 FP。
3. 点击 **「导出人工标注基准」**。此时浏览器才调用 Web Crypto 对**原始选择的文件字节**计算 SHA-256，输出 `draftai-photo-annotations.json`，包含有限原图像素几何真值、手输文字、原图尺寸与指纹；**不含图像、文件名、EXIF、浏览器 cookie**。
4. 在同一台或另一台受支持浏览器重新选择**字节完全相同的原图文件**，再次运行本地检测，并选择此前导出的 JSON。
5. 点击 **「核对原图并导入标注」**。仅当原文件 SHA-256、原图尺寸、数据契约、图形坐标、重复 ID 检查均通过时，一次性恢复人工标注，立即用**当前版本的识别候选**计算指标。不会把旧版本的检测结果或旧 OCR 状态带过来。
6. 仍可分别点击页面原有「导出无图片 JSON 报告」，得到本次检测误差结果；标注基准和误差报告是两个不同的文件。

## 数据与安全

- **不会自动导出或上传图片/标注。** 两个按钮都必须用户主动点击；无 fetch、XHR、localStorage、IndexedDB、外部 OCR 请求。
- SHA-256 **不是匿名化**。如果分享标注包，其中的手工文字内容和图片指纹可能识别所使用的原图，应自行谨慎保管。
- 用户更换或清空照片、重新运行检测、在等待 SHA-256 计算时修改标注，都会导致此前进行中的导入/导出请求放弃，不会误写旧题图。
- 只允许读入最大 150 KB 的标注 JSON，所有数据字段都按 #301 的明确类型和上限严格验证。任何失败都不会改动当前真值。
- 无 Web Crypto 的非安全浏览器环境会显示不可用，不会以不可靠的文件名或相同宽高代替身份判断。
- 指标依然只衡量**原图像素候选**的人工核对偏差，属于识图实验，不是毫米标定、数学唯一解、G1 连续性或 V5 作图真实性证明。

## 本轮验收

`node --test tests/workbench/v39-photo-annotation-replay.test.cjs tests/workbench/v39-photo-replay-browser.test.cjs` 包含真实 SHA-256 哈希、同源标注重放、错误照片/格式/元数据、过期修订、安全构建接线和零网络源代码边界。

仍须经过 GitHub 五项 CI 和 Android/浏览器实机验收。没有用户授权的真实原题和独立标注数据时，不得宣称已经测得实际陌生工程照片的识图准确率。
