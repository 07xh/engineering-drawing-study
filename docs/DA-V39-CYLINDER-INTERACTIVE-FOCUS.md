# DraftAI V3.9｜斜截圆柱浏览器图线点选、动态聚焦和手机触控

建立在已合并 [#299](https://github.com/07xh/engineering-drawing-study/pull/299) 的可信数学图元查询和真实 V5 步骤对应之上，这一批把功能接到了现有独立浏览器实验室 `/labs/cylinder-cut-live.html`。

## 实际交互

1. 点击或轻触**已画出的**已知图、辅助线、可见实线、隐藏虚线或待确认线型。通过 SVG 的 `getScreenCTM().inverse()` 将用户触点变换到当前实际缩放下的图纸像素位置；不假设手机屏幕为 960 像素，浏览器 API 无法使用时才使用有界的 `viewBox` / rect 后备计算。
2. 使用 #299 `scene.inspectAt` 判断当前时刻实际已绘图线的 12 像素触控命中，得到真实图元 ID、来源边、V5 所属步骤和该笔中间播放时刻。命中即暂停原播放器，seek 到这笔并高亮；没命中时清空选中，不推断任何数学图元。
3. **默认自动聚焦**：按当前真实步骤或选择的图元调用 #299 `focusOnStep` / `focusOnAction`，生成有界等比例 `viewBox`；每次全帧重绘时保留，绝不修改原纸面几何坐标、数学结论或线型。点击「查看整张图纸」关闭自动聚焦并还原完整视图。
4. 变更题目数据会清除旧图、旧选择和视框。手动进度/上一步/下一步/重新播放清空原来的图元归属提示。箭头左右键可在图纸获得焦点时逐步定位，步骤导航仍可直接点击。
5. 所有操作继续在浏览器本地执行。保存导出的 SVG 仍是原数学场景的当前完整帧，不把缩放聚焦后的子区域冒充完整工程制图结果。不上传用户数据。

## 限制与验收

目前仅针对独立 04 有界圆柱斜截实验台，仍要求明确定义单个 Z 轴有限圆柱、斜截平面、保留实体侧和每个视图的观察方向。不自动识别照片，不宣称正式第一角法观察方向或隐藏线符合工程制图国标；任何“未定”可见性仍需人工核对。此批不修改 01/03/07/08/09 的通用模块、图片识图主界面、CI 与生产配置。

测试：`tests/workbench/v39-cylinder-lab-tap-focus.test.cjs`（静态 DOM 控件及真实几何/选择联调）和既有 V3.9 inspector 7 组数学测试。GitHub Actions 通过只验证仓库代码和打包，不代替 Android 平板触摸精度/缩放和 Cloudflare 正式 Active SHA 验收。
