# DraftAI V4.0｜移动端原生平移与五点自检目标定位

DraftAI 是个人 AI 工程制图自动解题与 V5 动态作图系统；本改动仅完善已合并的识图验收工作台（#308、#310）的 Android 交互可靠性，**不直接增强数学求解或宣称已具备任意陌生题图解答能力**。

## 发现的真实交互缺口

V4.0 的图纸最多可放大 300%，但原 SVG 人工标注层始终采用 `touch-action:none`，移动浏览器不会原生滚动图纸。用户用单指移动放大后的大工程图，可能被当作“画一条线”，错误污染已保存的人工真值与 TP/FP/FN。

## 两种明确的操作模式

- **移动图纸模式**：点按“移动图纸模式”，容器开启浏览器的单指滚动（`touch-action:pan-x pan-y`），SVG 临时关闭指针命中。改变模式立即清除正在进行的标注手势；若五点自检还未结束也取消自检，以免误计触控结果。
- **标注图元模式**：点按“标注图元模式”，恢复原 SVG 的单指严谨标注逻辑，仍继续遵守多指、`pointercancel`、离开范围与丢失捕获的失效原则。切换模式不会修改原有标注、检测结果、OCR 运行状态或质量基线。
- 页面提供 `aria-pressed` 描述当前模式，避免 Android 上不清楚为何无法描点或移动图纸。
- 更换/清空图片自动回归标注模式，不继承旧图的正在进行的手势。

## 五点自检自动取景

五点触控自检启动后，页面会根据**目标原图像素坐标**以及当前 SVG 实际渲染宽高，计算安全滚动位置，把目标尽可能移至可视区域中心。点完一处自动定位下一处；改变图纸缩放后同样重新定位目标。这只改变 `stage.scrollLeft/scrollTop`，不改图纸像素坐标或任何人工真值。

## 验收与限制

`node --test tests/workbench/v40-photo-qa-native-pan.test.cjs`

测试覆盖放大图中心聚焦、左右上下边界滚动限制、无滚动需求、竖版工程纸、非法元素尺寸、切换模式清除手势以及 UI 事件/样式接线；还必须通过 GitHub 五项主干 CI。

CI 对滑动/坐标数学有可复现证据，但仍需在实际 OnePlus/ColorOS 的手机与平板浏览器上验收触摸行为、SVG 指针事件与 DOM 布局差异。Cloudflare 正式 Worker Active SHA 未核查之前也不能称为已上线。
