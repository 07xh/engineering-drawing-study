# DraftAI 04 V4.2｜棱柱动态作图网页的可信空间观察线型确认

延续已合并 [PR #311](https://github.com/07xh/engineering-drawing-study/pull/311) 的有限长方棱柱截线开边真实空间射线分类及 V5 独立可见/隐藏/未定三类 SVG 逐笔描画。这批将**人工确认入口**接入 `/labs/prism-cut-live.html`，默认继续保持未审定线型，不擅自代表正式第一角法下结论。

## 页面模式

- **未确认视向（默认）**：只需输入明确的长方棱柱尺寸及截平面，调用已有真实 12 棱解析数学求交、三视联系线、V5 动画；所有截交结果继续绘制为橙色待审核线型。
- **按明确射线判断可见性（需要主动选择）**：打开观察控制，必须全部确认截切后*保留材料是平面法向正侧还是负侧*，以及 V 图观察者在 Y 轴的正/负侧、H 在 Z 轴的正/负侧、W 在 X 轴的正/负侧。任一未确认，直接拒绝旧图，不做不透明的默认推断。
- 几何输入或观察参数发生修改，现有动画/结果立刻失效、重新运行数学引擎和真实 V5 时间轴。用户显式选定的 V/H/W 三个视向分别计算真实三维遮挡；开放线段被证实向外展示绿色实线、被实体遮挡展示灰色虚线、视线切向或共面等未证实部分展示橙色点虚线。
- 在画面下方显示当前模型三视**截面开边**的数学判别计数，未确认模式直言全部待审核；保留速度、单步回退、辅助线开关、SVG 本地下载，不涉及网络上传。

## 不能夸大

所有结论仅对应用户给定的**一个已知轴对齐长方棱柱**、一个已知非退化平面、指定保留半空间及空间视向；未经 03/09 签收正式的中国第一角法观察方向，未证明截面角点可见性、线型国标、其它零件遮挡或剖面面域填充。因此数学上 `openEdgeRayVisibilityVerified` / `visibilityVerified` 即使为真，也**绝非完整工程制图标准线型验收通过**。待确认页不能给出虚假的“标准正确答案”标志。
