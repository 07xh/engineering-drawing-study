# DraftAI V4.2｜图像候选 → 人工已知长度 → 毫米比例的安全校准

## 与旧版工作台的衔接

DraftAI 的产品定位仍是个人 AI 工程制图自动解题与 V5 动态作图系统。现有 `/labs/auto-fillet-live.html` 已有原图本地直线/圆候选检测、校正原图像素坐标、毫米校准、候选圆心、真实 02/G1 验证及 V5 逐线播放。但此前 `mmPerPx` 必须由用户先在别处手算并输入，容易发生像素当毫米或算错比例的操作错误。

本轮增加**可选、手工确认的已知长度比例助手**，只支持已经选择且编辑过端点的**完整有限线段**：

1. 在解题工作台上传自己有权使用的本地题图，运行直线检测，从候选中选择需要的有限线段。
2. 在「原图像素（可修改）」中校正这条线段的两个端点，确保**端点正好对应图纸上已知的那条完整尺寸跨度**。
3. 在「使用已知尺寸校准毫米比例」中选择该线段，手工输入独立核对的实际长度（毫米），明确勾选“端点和真实尺寸对应、单位为毫米”。
4. 点击「根据已核对长度计算建议比例」，计算 `mmPerPx = knownLengthMm / hypot(ΔxPx, ΔyPx)`。值会填入现有 `rasterMmPerPx`，供原有安全导入框架使用，不会直接生成解答。
5. 继续核对原点、Y 方向、第二个源图元和目标连接弧 R，勾选原有全条件 `rasterAccept`，再按「把审核后的照片几何导入毫米数学条件」。候选数学分支、方向、两侧原轮廓行进方向仍由用户明确选择并由 02/G1 独立验证，未通过不能播放 V5 结果。

## 重要的保守限制

- 这是从**已审核实际长度**推导的**一个建议比例**，不是自动测距、OCR 确认、摄像头透视校正或已证明的全图均匀毫米比例。被斜拍导致近大远小的题图，**不能直接拿一个基线比例用于其他位置**。此限制已写入 UI 和建议对象 `perspectiveAndDistortionNotVerified:true`。
- 原图像素线段小于 10px、两个端点无效/越界、实际毫米长度为零/非数字、来源 ID 异常及比例数值超限均拒绝。源图元必须是所选择的实际 **segment**，不能用圆弧的一部分、箭头翼或 OCR 文字框伪造。
- 修改两个端点、重新选择图元或更改已知长度时，旧的推导比例立刻清空，原有“全部条件已审核”勾选也失效；重新计算后仍须重新完成全图元与 mm 条件审核。
- 用户仍可跳过比例助手直接手动输入 `mmPerPx`；辅助算法只服务于数值填写，不改变原始几何求解器与正向 G1 验证。
- 图片始终在本地 Canvas/对象 URL 中处理，不上传教材、作业照片，运行中无网络请求。尚无 Android 实机或真实斜拍样本的现场验收，不能以 CI 通过冒充实景几何测量证明。
