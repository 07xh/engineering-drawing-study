# DraftAI｜C2 布尔新生棱的二维/三维同源联动

> 此批是此前 PR #957/#964 的 C2 几何来源延伸，不是第二套求解/动画系统。

## 真实数据流

已确认且受约束的 2–8 个轴对齐封闭立方体 → 原 M0/M5 `reviewC2OrthogonalBooleanFeatures` → 原 `proveGeneratedOrthogonalUnionCreases` 完整重算交叉核验 → 仅为带真实三维端点、源双面来源和 *positive open* 四象限证据的 concave union crease 建 `Geometry.segment` → **唯一 Geometry Scene** 第一角法 V/H/W → 原 SVG/Three.js 的 `sourceFeatureKey` → 原协调器的 revision-bound 双向选择。

数学来源 ID 与可用于 Geometry 契约的 ID 独立保存。绝不从二维图上相同的线段猜三维来源；新生棱不会“认作”任何一条旧 mesh 棱。积聚为点的投影仍保留同一个原始三维线段来源身份。

## 边界与保护

- 这些都是**有范围的三维开放区间候选**，即使是正向局部证明，也不能直接晋升国标可见/隐藏实虚线；闭区间端点拓扑、全体连续遮挡、重叠深度排序和 V5 正式笔画仍需既有 M4/M5 验证
- 只复用原来已签收的 M0/M5 算法，UI 不再手动重新投影生成 2D 候选，避免第二套显示坐标逻辑
- 切换“辅助线”同时关闭 V/H/W、SVG 三维和 Three.js 三维中的新生来源候选，不能让隐藏的棱通过 3D Raycaster 被选中
- 项目没有改变源用户条件，输入修订后必须重新计算；Three.js 是投影拾取和显示层，不是几何权威来源
- 新增回归：六条两面交叉的三维新棱；二维 12 条非积聚线、6 个积聚点、三维 6 条源棱；第三实体遮蔽局部片段；相离/接触；重算拒绝伪造来源
