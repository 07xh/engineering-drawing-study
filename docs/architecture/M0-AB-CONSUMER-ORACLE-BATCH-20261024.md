# M0 加速验收 A/B 批次：真实消费者与独立数学对照

此批次遵循 [2026-10-24 正式加速计划](./M0-ACCEPTANCE-FAST-TRACK-PLAN-20261024.md)，将相关但相互独立的 A（单位、像素→mm 及来源边界）和 B（精确方向/三维向量）消费者反例组合为**一个可回滚的测试增量**。不引入新的几何求解内核，也不改变已有 M0、M1、M3 算法。

- **A，已审像素→M1 实际消费者**：12 个不同等比例/平移/Y 轴方向实例，验证像素进入 `toModelMillimetres` 后必须重新带入明确 `model-mm-2d` 坐标标签，M1 `analyzeSegmentTopology` 得到相交、端点接触、重合和不相交结论。证实错误原图版本、图像 ID、原始像素坐标标签、错误单位均拒绝。此链仍仅来源于**人工审核**；`geometricAccuracyProven:false` 不变。
- **B，独立整数解析 oracle**：由独立 BigInt 方向计算得出非退化有限线段的解析相交/不相交结论，经过三个 2 的整数幂尺度和有限坐标平移，逐个与真实 M1 线段拓扑消费者比较。包含法向/端点方向变换以及 (2^{52}) 浮点交叉乘积假零反例。BigInt 仅出现在**测试中的独立 oracle**，不会进入拖拽/动画。
- **B，真实空间专业消费者**：实际 M3 棱柱斜截链使用同一 M0 object-vector Euclidean 与唯一第一角法投影器，水平有限截面由面积/周长解析公式独立核对；多尺度/平移/零法向/截面不相交均验收。独立 512 组三维 BigInt 行列式符号 oracle 覆盖 fast/exact 数值谓词输入，而不声称所有任意非线性曲面已证明。
