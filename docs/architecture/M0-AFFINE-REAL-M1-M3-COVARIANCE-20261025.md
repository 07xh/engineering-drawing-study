# M0 affine model-mm transforms: real M1/M3 and V/H/W consumer covariance acceptance

This is the next scoped M0 proof batch after [PR #679](https://github.com/07xh/engineering-drawing-study/pull/679). It does **not** add or alter a second numeric kernel: `core/numeric/affine-transform.cjs` retains finite-magnitude, fail-closed point/direction transforms, non-projective matrix restrictions and prior snapshot safeguards. All tests ACTUALLY invoke production modules using transformed source data, rather than only comparing the affine matrix routine with itself.

1. The REAL `core/geometry/segment-topology2d.cjs` M1 consumer must keep proper-crossing, endpoint-touch, collinear-overlap and disjoint classifications under 2D model-mm rotations, reflections, anisotropic scales and translations. Reflection reverses orientation but cannot change incidence/topology; coordinates are checked against analytic transformed endpoints, preserving M1's represented-binary64 guarantee only.
2. The REAL M3 `rectangular-prism-plane.cjs` section consumer must preserve horizontal 10×8 mm prism area `80*k*k`, perimeter `36*k` and independently known z section under finite positive uniform scales and 3D translations. Every result passes the one first-angle V/H/W model projection from `core/projection/conventions.js`.
3. The REAL M3 finite cylinder lateral section and finite segment/plane consumers must respect radius `5*k`, analytic plane z and exact segment parameter `0.25` after the same common affine transform. They may not grant global uniqueness or hidden-line/V5 styles.
4. The shared REAL pairwise V/H/W edge depth consumer must keep first-angle front relation and scale mm depth difference by k, without promoting complete scene, joins or standard lines.
5. Two composed affine transformations are checked against nested physical coordinates. A non-invertible transform resulting in a collapsed source, pixel-labeled M1 input and numerically overflowing geometry must be rejected downstream. Tests only use exactly representable binary64 powers-of-two scales and translations, avoiding fabricated photo accuracy.

The new executable test is referenced in the existing 20-module M0 inventory.
