# DraftAI M0 → real M3 model-mm 3D geometry consumer input consistency

This batch closes a shared M3 **validation versus calculation source integrity bug** while reusing the one M0 `object-vector3` / `euclidean-kernel` and canonical `project` V/H/W. Existing specialists had validated each caller-owned point or normal via property getters, then read those getters again when normalizing planes, checking cylinder sizes, collecting prism corners, or classifying prism open-edge visibility. Different values between reads could silently change the model-mm mathematics that was supposedly validated.

Changes are localized to pre-existing consumers: `axis-cylinder-plane.cjs` snapshots model-mm plane point, normal, finite cylinder center/radius/height and finite segment endpoints exactly once; `rectangular-prism-plane.cjs` exposes the same verified `snapshotBox` used by prism section construction; `rectangular-prism-cut-visibility.cjs` passes the same owned normalized plane, owned prism box and snapped observer to both M3 section and open ray visibility instead of reading the untrusted box/plane again. There is **no new numerical kernel or second solver**.

Independent real-consumer regression uses an analytically known plane z=5, segment z=0..20 (intersection t=1/4), finite cylinder (radius=5 centered at (2,-3), full 33 sampled points on z=15), prism 10×8 cut at z=5 (area=80 mm²/perimeter=36 mm), and prism retained negative-halfspace with +Z observer (4 locally visible open edges). Every source point, plane, box bound or size with a dynamic getter returns an invalid/contradictory value after the first valid read, and test asserts the number of reads is exactly one. Invalid initial values, zero-width solids and degenerate line refuse rather than returning verified mathematical results. V/H/W projections and `v5LineStylesReady:false`, `boundaryEndpointsVerified:false`, `globallyUnique:null` remain unchanged.

**Scope:** model-mm analytic single solid/plane source only. These tests cannot authenticate scanned textbook photo, arbitrary complete scene, CAD front/back hidden-line continuity, closed endpoint topology, full ConstructionIntent/DAG/unique V5 playback or production Active SHA. Extrema precise sign in M0 may be certified for the represented binary64 sign, whereas ordinary M3 distances/numeric coordinates must still reject unrepresentable magnitudes.
