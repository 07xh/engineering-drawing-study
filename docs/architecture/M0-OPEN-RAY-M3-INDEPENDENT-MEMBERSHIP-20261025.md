# M0 open-ray sign primitive × three real M3 section consumers: independent physical oracle

Refs #372/#152 and the accelerated M0 verification plan. Unlike the last two phases (#665/#667), the shared `convex-open-ray.cjs` primitive does **not** own a raw 3D source vector: it already accepts validated signed scalar slopes and returns only four local cases. Adding a competing ray kernel or a global 'visible' certificate would be architecturally wrong.

This batch **executes the three existing M3 consumers**: verified box plane-cut open edges, finite Z-axis cylinder analytic lateral arcs, and upright cone analytic section arcs. Rather than merely self-comparing the scalar classifier, an independent physical oracle perturbs each mid-arc/source-face point a small positive distance in the viewer direction, then checks the original geometric solid membership and chosen cut-plane *kept* halfspace. A locally signed `hidden` result must enter the strict finite retained solid; a locally signed `visible` result must be outside it. This is a finite-domain **necessary consistency check**, not a proof that a sample certifies the WHOLE arc: the existing specialist mathematical partition must still prove constant sign over its open interval.

For the rectangular prism the test additionally derives face-normal and kept-plane signs **directly from integer 3D coordinates**, without trusting the M0 scalar slope, and checks every reported edge run. Also tests normal reversal *with* retained-side reversal as an independently equivalent halfspace for prism and cylinder, and tangent directions refusing any certified edge. For cylinder/cone the oracle uses only analytic equations of finite circle/cone volume and cut plane, not the specialized classifiers' internal visibility reasons. Multiple observer directions and both retained sides must produce actual visible and hidden witnesses.

**Signoff boundary:** Tests use explicitly supplied analytic single-solid model-mm geometry, not independent authenticity of photographed source input. Neither local halfspace/ray sign nor a sampled membership check proves all endpoints/silhouette transitions/occluder enumeration/official V/H/W line style/ConstructionIntent–DAG–single V5. Source revision and retained-halfspace confirmation outside this sample family remain pending. Accordingly only append an actual-consumer independent-oracle test to the existing 20-module acceptance matrix; retain `consumer-review` and a concrete remaining gate. No mathematical engine, source parser, animation player, CI config or production deployment changed.
