# 第一章 · 纸面作图动态实验（三类原创模型）

本功能是根据胡建生《工程制图与 AutoCAD》第3版第一章的知识主题自行开发的数学与SVG学习演示。**不公开教材PDF、原图或出版社答案。** 下列印刷页码来自用户提供的完整教材；PDF页码=印刷页码+6。

## 1. 线段等分（印刷第13页 / PDF第19页）

教材第一章第三节的“直线的等分”使用过端点的辅助射线、等距离标记和相似三角形平行联系线来等分给定线段。教材例题使用七等分；本站允许2～10段，只是数学上同一方法的原创参数化讲解，线段坐标和图形布局完全重新设计。

数学验证：若A、B固定，在辅助射线上等距得到点P(k)，令P(n)与B相连，再过P(k)作该直线的平行线，交AB于Q(k)，则由相似三角形可得 AQ(k)/AB=k/n。检查所有相邻Q间的长度是否相等。

自由度说明只对“一个已知属于AB的待求分点”而言：从在AB上任选位置的1个连续自由度，到由等分比例固定位置的0。辅助射线方向本身具有人为选择自由度，不计入待求分点的DOF。

## 2. 正多边形（印刷第13～14页 / PDF第19～20页）

教材在“圆的等分及作正多边形”中展示内接多边形的作图；本站用原创固定外接圆的数值模型实现3、4、6、8边形，顶点由等角 \(2\pi/n\) 构造，不声称复刻教材的三角板尺规过程。

数学验证：顶点到圆心距离都等于R；相邻边长均等于 \(2R\sin(\pi/n)\)。六边形时边长等于R。

自由度解释：外接圆与边数固定但首顶点方向未定时，整体旋转仍有1个连续自由度。规定第一个顶点的方向后，整个正多边形旋转自由度为0。这里不是分别对所有顶点的自由度求和。

## 3. 定形尺寸与定位尺寸（印刷第21～22页 / PDF第27～28页）

教材第一章第四节明确区分决定形状大小的定形尺寸和决定位置的定位尺寸。演示用一个给定半径的圆说明：R仅决定圆的大小；圆心两个平面坐标仍需两个独立定位条件才能确定。

模型：原点作为横纵基准，圆心为C=(x0+dx,y0-dy)。第一条竖直定位线固定C的x坐标，第二条水平定位线固定C的y坐标；其交点是圆心。演示DOF 2→1→0并核对圆心至基准的两个差值。

这些画布坐标不是书中图样的真实尺寸或工程制图毫米值。原题若有其它约束、两定位条件平行或不独立、或者只有角度/半径，都需要另建方程验证，不能套用这个简单情形。
