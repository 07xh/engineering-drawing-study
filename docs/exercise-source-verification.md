# 图学课堂 · 教材原题复刻前的证据与审核规范

## 已有资料不能混为一谈

1. 用户提供的 23 页《工程制图.pdf》：目前主要作为工程制图投影理论知识卡（对应印刷第 31～53 页）的知识来源，包括三视图、点线面、平面/曲面立体等图学概念。这些教材示例图号（如“图 2-9”）**不能推定为**题库编号“2-9-1”等对应的作业题图。
2. 仓库 `labs/verified-exercises.js`：28 道练习的**部分**可辨认已知线、圆和点的录入，资料标注约为“教材第 15～18 页”，全部现为 `partial`。这不代表它们已对照完整原图逐项验算，也不代表资料必定来自上述 PDF 的同名页。
3. 公开资料检索：方法教学、相似例题、工程制图通用规范和百科/文献元数据只能提供**候选方法**；不能直接证明教材具体原题的已知条件或答案。
4. `labs/point-construction.html`：原创可验算样例，坐标可任意调整，允许故意引入错误候选点。与教材作业答案完全分离。

## 每一道原题必须有的审核材料

- **原始题图**：清晰、完整、有版次、对应页码、图号与题号的原始资料，须确保所有投影轴、隐线、文字、尺寸及重影点均可辨认。
- **已知量登记**：每个空间点与同名投影建立映射，标明画布显示坐标和真实毫米尺寸之间的换算关系（若无法读取比例，不得将像素声称为毫米）。
- **几何约束清单**：识别平行、垂直、共线、共面、相交、曲面归属、圆心半径、点的前后/上下位置与可见性；记录每一条约束究竟来自哪里。
- **独立解法**：可以有多种候选方法；逐步校验每个辅助线的两端点、空间归属及与其他视图的同名点关系。相似题的公式或图不能直接代替原题验算。
- **结果验证**：检查所得点线是否满足全部已知约束、是否唯一；如存在两个镜像/前后候选，应呈现歧义而不是任意选一个。
- **人工确认和版本绑定**：确认完原图后生成不可混淆的版本标识，再审阅独立计算结果；先验证再开放真正答案步骤。

## 当前新增的两个工具

### 原图核验总览
`labs/source-fidelity.html`：覆盖 28 道题，显示现有已录入点线圆和缺少的条件，进行机械级检查（越界、退化、重复线段和转移线角度的可疑点）。

**局限**：自动发现的结构警告是复核线索，不能证明教材或原图数字化结果有错；一条线坐标合法也不能证明该线对应教材原图。

### 可验算的第三投影实验室
`labs/point-construction.html`：根据原创空间点 (x,y,z) 的 V 与 H 投影，用长对正、高平齐和 45° 深度转移构造第三投影 W。自带故意矛盾的 W 点候选，调用共享三维线性约束引擎进行独立一致性检查。

**局限**：这是真实的数学/投影逻辑演示，不是教材第 2-6～2-9 任一道原题的答案。能够验算模型，不能取代教材原图审核。

## 后续建议的逐题顺序

建议先对每组中图形与已知点较清楚的题进行完整核对，例如 2-6-1、2-7-1、2-8-1、2-9-3；具体优先级还需以清晰原图为准，而非仅看网站已登记图形数量。每次只将**已确认的原题已知线**加入原图层，再单独生成并证明解法数据。

### 绝对禁止

- 把通用示意图、AI 猜测线、搜索引擎标题匹配当成原书准确已知图或标准答案；
- 把本机标记“已对照”当成正式 `coordinateAudit`/`solutionAudit` 通过；
- 没有版次、点位、投影关系及可见性证据就将 `partial` 改为 `verified-complete`；
- 把用户上传的教材扫描图、文字长段或出版社答案直接公开提交到仓库。
