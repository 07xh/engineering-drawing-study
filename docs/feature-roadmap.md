# 图学课堂后续功能方案

目标：让学生能顺畅完成“找到知识点 → 理解作图 → 核对结果 → 下次继续”的学习过程。延续现有教材体系，不补写未经原书核实的题目或答案。

## 本轮已实现（待合并与上线）

- 首页优先展示前三章，折叠后续目录；依据本机上次浏览记录提供继续学习。
- 知识库默认显示已核对讲解；待核验章节和深链接仍可访问。
- 按当前筛选结果切换前后知识点，显示位置与边界状态。
- 筛选无结果时直接展示恢复入口；标记已学习后同步更新未学列表。
- 修复进度保存失败提示被覆盖的问题；阅读标记不代表掌握。
- 习题卡片简化提示，明确描图核验状态，支持章节主题搜索。

## 第一阶段：学习闭环（优先）

| 功能 | 使用方式 | 验收要求 |
| --- | --- | --- |
| 章节学习面板 | 显示已开放讲解数量、阅读进度、继续学习入口 | 目录导学不计入已核对讲解的完成率；切换筛选不改变统计口径 |
| 收藏与待复习清单 | 知识点可收藏、加入待复习；从清单回到原知识点 | 阅读、收藏、掌握分开记录；浏览器拒绝存储时明确提示 |
| 学习记录导出与恢复 | 导出本机记录，在另一浏览器手动恢复 | 文件包含版本；校验知识点 ID、大小及格式；合并预览后导入，不默认覆盖 |
| 搜索体验 | 题号、知识标题、术语与章节检索；显示匹配位置 | 空结果可恢复；待核验条目有状态；搜索不猜测习题所属教材知识点 |

建议先做章节面板与收藏，再做记录导出。此阶段可沿用静态网站与本机存储。

## 第二阶段：图形教学与题目核验

| 功能 | 使用方式 | 验收要求 |
| --- | --- | --- |
| 分步作图播放器增强 | 当前步骤高亮，已知线、辅助线、结果线区分；重播与速度调节 | 每一步对应已核验的教材例题；不能仅靠颜色区分；支持减少动态效果 |
| 手机看图模式 | 放大、平移、复位，图形与当前解释便于切换 | 放大后尺寸与点名仍清楚；不误触翻页；退出后返回原步骤 |
| 结果自检清单 | 依知识点列出投影对应、尺寸、可见性等检查项 | 明确是自检记录；未验证前不提供“自动判分”承诺 |
| 题目核验工作台 | 记录来源页、题号、已知条件、缺失项与审核状态 | 未完成审核不能发布标准答案；状态变更有记录；原书扫描页不进入公开产物 |

内容优先级：先把已核验的例题体验做完整，再按教材逐页扩充。通用六层讲解先选择少量重点知识点逐条重写，核对后推广，避免批量生成同质化内容。

## 第三阶段：账户、私密资料与教师功能

前置决定：确认主要使用者是个人、一个班级还是多位教师；确定资料授权范围与部署平台，再选择具体身份认证和存储服务。

- 账户与进度同步：登录后跨设备同步，明确本机记录迁移与冲突处理规则。
- 私密资料区：服务端验证身份、按课程授权、受保护的文件访问；通过退出登录和其他账户访问验证隔离，不能依赖隐藏前端链接。
- 教师内容后台：草稿、核验、预览、发布和回退流程；公开与私密产物分开检查。
- 作业与反馈：教师布置已核验题目，学生提交步骤与图纸，教师给出反馈。先支持人工评阅，自动几何判定单独论证。

## 发布与质量要求

1. 继续使用现有仓库和域名的发布流程。Sites 当前未识别到这个网站的项目，因此不另建副本替代线上站。
2. 每批改动经独立分支、自动检查和预览后再合并；先核实现有 Cloudflare 构建设置与产物目录。仓库早期部署说明与现有 `dist` 构建方式存在差异，需要以实际部署配置为准。
3. 浏览器验收覆盖手机和桌面：首页入口、筛选、深链接、进度更新、例题播放器，以及禁用本机存储时的提示。
4. 不把未做的浏览器验证或完整构建标记为通过；未核实的教材内容保持原状态。
5. 暂缓排行榜、复杂积分、全站 AI 自动答题和批量自动判分，先确保核心学习过程与来源可信。
