# DraftAI 公开基础功能 / 私人 AI 施工边界

> 施工记录：2026-10-21。本文是上线计划与当前限制，不是已上线的 AI 能力声明。

## 本批已改造

- 首页以现有公开几何工具为主：点投影陪练、同纸三视图与自由度、自由几何建模、圆弧连接教学实验、尺规几何及组合体可视化。
- 教材课程目录不再是首页主入口；旧知识/审核页面仍存在、仍可经 URL 访问。
- 新增 `public-use.html` 说明公开范围、模型状态、学习限制和资料边界。
- AI 识图暂未开放：没有上传控件、没有对外模型 API、没有公开用户数据库。
- 将首页产品定位与版权/隐私边界纳入自动检查，并更新旧教材首页检查以保留实际知识与原题核验测试。

## 必须正确理解的公开边界

- **所有位于 `dist/` 的资源都按公开资源处理。隐藏导航不代表受保护。**
- 现有打包列表仍包含一些旧的教材知识与练习核验页面。上线前必须逐项确认内容来源、图像和版权状态；不能因为首页更名就认定这些路径安全。
- 个人教材 PDF、题目照片、私人错题记录与 API 密钥禁止出现在 `dist/`、公开 GitHub 仓库、客户端 JS、浏览器日志或普通 PR 描述中。
- `robots.txt` 不构成访问控制。私人 AI 与资料存储必须有独立服务端鉴权。
- 不要将仅通过限流保护的开放上传当作“私人”。如接入个人 AI，需要服务端身份验证、上传限制、密钥管理和必要的数据删除流程。

## 下一步：分批验收

### P1：公开页面浏览器验收

1. 检查首页与公开工具入口、安卓平板横屏和手机布局。
2. 完整运行 GitHub Actions、检查生成资源链接。
3. 对 `dist/` 执行敏感文件/教材扫描件核对；旧公开知识和习题页面做版权审计。
4. 部署到预览环境验证后，再考虑合并与正式部署。

### P2：真正的个人 AI 区域（**尚未开始**）

1. 在 Cloudflare Worker 服务端实现独立鉴权（例如经 Access 验证的专用后台/API）。
2. 服务端单独保存模型密钥，严禁写入前端。
3. 上传图片必须校验内容类型、大小、配额及访问身份；资料存储默认私有。
4. AI 识图只负责生成候选条件，用户确认后才调用已验证的几何求解器。
5. 未受支持的题型不能声称输出准确的自动答案。

### P3：可选的公开 AI 体验（**尚未决定实施**）

仅当费用预算、服务商条款、限流、滥用控制、数据处理说明及数学验证全部完成后，才单独上线限额的公开试用入口。默认不开放。

## 构建/测试

当前仓库采用 allowlist 复制式静态构建，请同步维护 `scripts/build-static.cjs`。
`scripts/check-public-entry.cjs` 用于检查主页入口和准确的 AI 状态提示；保留 `scripts/check-textbook-only.cjs` 对已校核知识、未核实习题和答案发布闸门的回归检查。

本批不会触发生产环境部署，也不会合并到 `main`。
