- 安卓平板触笔：自主作图、放大后命中、缩放与页面滚动；图片候选框选坐标。
- 真实浏览器的图片/SVG 输入、原生 OCR 不支持回退、SVG 与步骤 ZIP 下载。
- 最终发布时再次同步最新主分支、CI、Cloudflare 预览和 production active deployment SHA；核对线上资源字节。

当前会话没有可调用的浏览器控制或安卓设备工具，以上项目不宣称通过。全部通过后用单独的统一切换提交更新正式构建映射，仍只发布 dist/。若失败，撤销切换提交并重新部署上一版经过验收的提交；不要回退期间新增的独立数学功能。
