# DraftAI 全站 UI 重构实施计划

> 当前会话使用 superpowers:executing-plans 逐项实施；不并行分派开发。

Goal: 全站统一界面，深度改造三类解题流程，不影响现有数学和功能开发；全部验收后一次切换。
Architecture: 独立 worktree；构建时增强已发布 HTML，原页面、控件 ID、数学入口及结果协议保持兼容。预览产物 dist-ui-next 与正式 dist 隔离。
Tech Stack: HTML/CSS/JavaScript、CommonJS、esbuild；linkedom 仅构建及 DOM 回归使用。
Spec: ../specs/2026-10-22-ui-refactor-design.md

## 全局约束
- 不改数学内核、识别算法、验证规则、导出格式或 V5 时间轴。
- 不实现题库导入、账号、云存储和新识图能力；不显示虚构保存或知识接入状态。
- 保留旧 URL、控件 ID、图元 ID、单位、动态状态和事件绑定。
- 所有公开页面统一导航、触控和响应式；主流程使用画布及上下文面板。
- 新版只能进入独立预览产物，真实浏览器和安卓设备门槛未通过不得切换生产。

## Review Focus
- 构建增强不可丢失控制项、脚本、隐藏状态或内联数学数据。
- 布局操作不可触发求解、丢失输入或绕过旧结果失效规则。
- 小屏不可隐藏唯一操作或造成页面级横向溢出。
- 不把未审核知识、实验候选或待选分支包装成正式答案。
- 预览与正式目录隔离，不扩大公开资料范围。
