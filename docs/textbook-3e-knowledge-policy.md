# 第三版教材知识库：来源、覆盖范围与重建规则

## 唯一教材基准

用户上传的完整 PDF：胡建生主编《工程制图与 AutoCAD》第3版，机械工业出版社，共292页（包括封面、目录和末尾非正文页）。网站**不会**公开存储此 PDF 或其页面图片。

目录依据 PDF **第6页**；正文印刷第1页对应 PDF 第7页，即 `pdfPage = printedPage + 6`。检索条目必须同时标出印刷页码和 PDF 页码。

## 本轮重建

- 旧的 `knowledge/knowledge-data.js` 31条自拟知识总结全部移出当前知识系统。旧的哈希 ID 不会当成新教材知识继续解析。
- 12个章节、53个正文小节、3个附录按目录重新建立独立索引。
- 现已对照 PDF 对应页面建设第1章20条、第2章16条、第3章18条重新编写的教学讲解。它们分别聚焦制图与纸面作图、投影基础，以及组合体的形成、截交线、相贯线、三视图、尺寸注法和读图。
- 第4～12章的目录标签与页码已经整理，但**其正文、图表和作图方法仍待逐页分析**；页面 `toc-only` 标志不可自行消除。
- 第2章“动态示例”的图形和自由度仅对原创数学模型成立，不能被视为教师原题的答案或真实图纸。

## 学习卡状态与诚信边界

### `toc-only` 目录已核实

可阅读：教材所属章/节、页码、导航、章节关键词。不显示未经校核的口诀、公式、自动辅助线或练习答案；不将“查看目录”计为“已学会知识”。

### `page-reviewed` 正文已复核并整理

可阅读：重写的简明解释、规律、原理、作图步骤和常见误解。若对应该知识点有确实适用的原创数学图例，可提供示范级动画，但**不能用一般点的自由度去声称整道实体题的自由度**。

### 原书题目独立审核

本次教材目录中的数字（如第2章、第6节）**不等于**原有习题的形如 `2-6-1` 的内部编号。目前 `labs/verified-exercises.js` 的28条为部分描图且来源未核验，维持 `partial`。不得仅凭名称建立配套题，不得从通用网络资料给出推测标准答案。

## 后续逐页建设顺序

按用户的纸面工程制图学习阶段，优先完善第一章“制图的基本知识和技能”、第二章投影基础（已开始）、第三章组合体及第五章图样基本表示法。课程进入CAD后再逐步开展第十二章内容。

开展单节内容前，应打开本书对应页面，读懂正文、图形和已知尺寸，登记证据页码；之后撰写讲解并验证自由度与原题是否有直接关系。版权受限的图片不公开复制；若用户需要带原图的私密解析，先完成真实的访问控制和私密文件存储，再存储受保护内容。

## 回退方法

旧知识库在 GitHub `main` 的重建前 Git 历史中，原 `knowledge-data.js` 文件未被永久销毁；不向站点当前界面展示旧条目。浏览器旧阅读记录使用 `drawing-knowledge-read-v1`，新版独立使用 `drawing-textbook-3e-progress-v2`；两者不会互相覆盖。
