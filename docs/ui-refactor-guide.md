# 图学课堂 · 页面与交互规范（UI v1）

## 目标与范围

将首页、知识库、章节练习、原题作图、原图核验以及主要几何实验室统一为自然语言优先、平板和手机友好的学习界面。仅重构 UI 和信息架构；教材原图、步骤验算、个人笔迹、学习进度、权限和原题答案审核完全独立。

## 导航与主要路径

- 首页先展示“课程 / 动态作图 / 课堂练习 / 知识库”，不把所有技术实验室横向挤在顶部。其余工具在“更多工具”中。
- 知识库：桌面/平板两栏，左侧搜索和知识目录，右侧当前知识完整解释与步骤；下方直达该知识的原创动态几何演示。小屏改为纵向阅读。
- 章节题库：保留题号、章节、复习标记与搜索，不把审核状态“部分录入”当成标准答案已核实。
- 原题作图：先显示当前原题画布，再按需展开“原图逐线核对”、“自由度分析”、“参考方法”、“联网检索”；保留 2-6-1 专项已知线核对。
- 原图核验总览：同页左侧列表右侧详情，减少从题目列表来回跳转的次数。
- 直线投影、约束实验室、平面投影教学：沿用自身成熟的作图控制，追加统一顶部导航与视觉规范。
- 大型历史 `labs/v7.html` 暂时保持独立，不对其大量旧代码做高风险覆盖。

## 代码及维护边界

- 公共视觉规则放入 `site-ui.css`，用 `body.ui-refresh` 限定作用域。
- 原页面特有画布、刻度、SVG 控件仍可在自己的 `<style>` 中定义。公共样式要避免强制修改 JS 依赖的元素 ID、DOM 引用顺序和画布坐标系。
- `details.site-disclosure` 只控制“是否展开显示”，不会主动调用检索接口，也不会禁用内部 JS 控件；用户仍可自主展开使用全部功能。
- `site-ui.css` 必须由 `scripts/build-static.cjs` 复制到构建目录。
- `scripts/check-ui-layout.cjs` 校验导航相对路径、关键控件 ID、四个折叠功能区、作图画布、知识库与审核列表完整性。
- 浏览器本地存储使用已有键；重构不能清除学习记录和个人画线。

## 实机视觉验收（尚需上线预览后人工确认）

1. 手机 360～430 CSS px：顶部导航不挤压正文，“更多工具”可展开；知识库卡片单栏，知识步骤和动态图可滚动查看。
2. 平板 768～1024 CSS px：知识目录和阅读区双栏显示，原题画布可以横向滚动，不遮挡笔绘操作。
3. 桌面 1280 CSS px 以上：首页侧边课程目录适度固定，知识阅读区和原图核验详情能独立滚动。
4. 选择 2-6-1：已有线条蓝色高亮不被折叠层遮挡；个人线条仍可开启、保存、撤销；原题解题按钮对未核验内容保持禁用。
5. 无网状态：联网检索失败应只显示提示，不应影响已有习题或知识卡。
6. 带 URL 参数的知识库章节练习入口、题号哈希、返回首页及其他跨页导航正常。
7. 键盘、触摸和触笔均可使用按钮；开启系统减少动画后页面可正常阅读。

**当前状态说明：** GitHub Actions 通过仅证明静态文件和部分脚本逻辑通过自动检查，不等于已经完成所有平板/手机真实浏览器验收，也不证明 Cloudflare Pages 已部署。
