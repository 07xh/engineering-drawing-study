# 图学课堂：教材题目统一接入规范（第一阶段）

目标：题目即插即用，但不把“可以渲染”误认为“已经自动解题”。

## 统一数据
- `id`：稳定的题目编号；`title`：题名；`type`：题型。
- `source.book` / `source.page`：教材及页码；`source.answerRef`：经过核验的标准答案来源标识。
- `status`：`source-pending` → `source-verified` → `steps-verified` → `solution-verified`。
- `givens`：题目已知条件数组；`steps`：分步作图数组，每步有 `id`、`explanation`、`actions`。
- `renderMode`：`manual-steps`、`constraint-engine`、`geometry-engine`。

## 安全边界
1. **不自动编造原题图、尺寸、辅助线或标准答案**。来源未核验的题目只能登记元数据。
2. 只有核验后的步骤才可驱动教材题目动画；自动几何求解另需题型算法及回归验证。
3. 原始扫描图、题干、答案与自制教学模型分开存储；公开部署时应遵守教材版权授权范围。
4. 现有章节知识点、原创几何演示和已收录习题保持原状，本阶段不批量迁移、不删除。
5. 引擎需要对每个绘图动作验证坐标、关联已知条件及推理依据；不支持时明确标记“待实现”。

## 后续演进
- 第二阶段：增加带版本的题目 JSON 数据、独立校验器和导入界面。
- 第三阶段：将“已核验的教材步骤”转换为通用 SVG 动画动作。
- 第四阶段：按点、线、面、立体、截交、相贯等题型逐项实现自动求解与可见性检查。

本规范只是可复用接口的基础，不宣称当前所有教材题目已经可直接导入或自动解答。
