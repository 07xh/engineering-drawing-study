帮助与用户协议

DraftAI 用于工程制图解题与逐笔作图。选择题型、确认条件、查看图纸和步骤。

如何使用

从“AI 解题”或“题型中心”进入对应工作台；修改题目条件后重新求解。播放、上一步、下一步和图纸缩放均在图纸附近。

当前支持有限的圆弧连接、点投影、正多边形及部分基本体截切条件。遇到多解、缺失条件或未经核对的图元时，需要先人工确认。

使用须知

图纸和步骤仅在其适用条件与验证通过时作为解题参考；工程尺寸、投影位置及线型仍应按题目要求复核。未通过验证的结果不应视为完整标准答案。

本站是持续完善中的个人工具，不能保证每张工程题图都能自动识别或求解。

数据与隐私

部分已有功能使用浏览器本地计算或本地存储；是否保存、导出及是否联网，以各功能的实际提示为准。个人资料、登录密钥和受限制的教材原图请不要提交到公开 GitHub 页面。

网站尚无统一的个人云端题库；清理浏览器数据可能清除本地记录。

AI 识图是否已经开放？

尚未向公众开放 通用图片识别和任意陌生题目一键解答尚未完成。已提供的本地图像检测与人工确认功能不等于自动解题已通过验收。

哪些内容可公开使用？

公开页面提供有限题型的计算和作图工具。教材专属资料与用户私有原图不会作为公开站点资源打包；部分实验仍需逐题验证。

问题反馈

如发现错误，可在 GitHub Issues 提供不包含个人信息的复现步骤。
