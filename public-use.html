公开范围与使用说明

DraftAI 的唯一产品方向是个人 AI 工程制图自动解题与动态作图：识别题图、确认条件、通过数学引擎求解、生成真实作图步骤，再由 V5 绘制动画。项目仍在建设中，目前公开可用的是部分数学、投影与几何绘图基础模块；实际支持范围以各工具为准。

哪些内容是公开的？

公开构建仅包括首页、部分投影/自由度/几何建模/圆弧求解工具，以及必要的基础绘图与约束算法。教材专属课程、例题及用户题图描图数据不随公开网站打包。现有实验工具将作为新版自动解题系统的可复用组件。

部分几何演示为限定输入条件的数学实验，不能直接视作任意新工程图题目的完整答案。

AI 识图状态

尚未向公众开放

当前尚无可用的 AI 图片上传与陌生题端到端自动解题入口。研发遵循数学基础 → 二维求解 → 自动 ConstructionStep → V5 动画 → AI 图像识别接入的顺序。请勿将现有基础几何工具误认为已上线的通用识图解题服务。

如未来启用 AI 识图，会先说明图片处理方式、模型服务、上传限制和相应的保护措施。

个人资料与浏览器记录

请不要向公开网站页面、公开 GitHub 仓库或公开问题反馈提交个人作业原图、完整受版权保护的教材扫描文件、密钥和其他私密资料。

部分现有学习工具可能使用浏览器本地存储保存设置或学习进度。本地记录通常不会自动同步到其他设备，清除浏览器数据也可能移除这些记录。

网站目前未提供统一的私人云端题库。未来如有个人资料上传功能，需先建立受保护的存储和身份验证机制。

教材与学习答案

旧知识索引及教材研究资料不是产品核心入口。未经真实几何与来源核验的原题和解答不作为标准答案使用。

公开工具不提供完整教材 PDF 的公开下载。使用教材原图和其他受限制资料时，需要尊重来源与相关授权。

有问题怎么办？

如果遇到几何计算或界面错误，可通过项目的 GitHub Issues 反馈可公开的问题描述，但不要公开个人照片、课本扫描页、登录信息或密钥。
