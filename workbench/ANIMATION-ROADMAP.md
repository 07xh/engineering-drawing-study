# DraftAI 动态制图系统：局部重构，不推倒整个网站

审计基线：2026-10-22；代码检查范围为 main 的教学播放器、教材例题、点投影、圆弧连接、自由建模、07 合成工作台。**未完成生产域名真实浏览器视觉/触控实测**，不要把源码审计写成正式上线验收。

## 决策
**保留现有生产站点、数学引擎、第一角法规则、教材来源门禁和用户历史成果；统一“求解结果→可验证作图步骤→时间线→渲染→自由度/残差/教学解释”之后，再增量扩展 04–06。**
不采取页面全量推倒重建，也不再让每个题型复制一套独立状态机和绘图坐标算法。

## 源码现状
- `engines/projection/point-projection.cjs`：支持 V/H/W 任意两面组合、直接 XYZ 输入、45°转移、数值残差和无解/欠约束门禁。`labs/point-projection-live-entry.cjs` 按步重建 SVG，重算时清空旧步骤。
- `engines/planar/**` + `labs/circle-fillet-live-entry.cjs`：真实圆弧连接求解、候选选择及 G1/有限线段判断；逐步揭示辅助轨迹、候选圆心、切点、弧。
- `knowledge/textbook-example-ui.js` / `knowledge/drawing-player-ui.js`：教材来源经审核的示例独立管理播放索引、帧与文本；`DrawingActionRenderer.svgMarkup` 与 SVG DOM 命令存在平行绘图实现。
- `labs/free-geometry-sheet.js` / `labs/free-modeler-ui.js`：同一空间点线三角面数据联动第一角三视图与 SVG/Three 观察器；当前自由度统计是自由点的 3N，线/面拓扑不等于几何约束，尚不是任意约束求解器。
- `workbench/**`：三模式（完整、提示、自己画）、synthetic fixture、图层分离和解状态门禁；尚未消费真实 SolveResult/ConstructionStep 的完整动态闭环。演示图绝不能被称作教材标准答案。

## 最需要控制的技术债
1. **多个独立步骤状态机**：无法保证所有题型的帧索引、输入修订、撤销、候选分支与解释同步；优先统一不可变 timeline + active step + input revision。
2. **多套 SVG 绘制路径**：SVG 字符串与 createElementNS 混用；统一中立的绘图动作列表，具体渲染可保留 SVG（纸面）和 Three.js（已确定立体），不应强行共享同一画布。
3. **模型坐标与屏幕坐标隔离**：模型用 mm + 第一角法投影规则，SheetTransform 负责成图与缩放；不得把纸面像素当数学求解条件。
4. **动画跳帧**：当前主要是步进显示；将“经验证的新图元”与“显示过渡”分离。可以逐线描画、强调新增线、暂停和速度切换；动画效果不能决定数学结果。
5. **真实浏览器验收缺失**：静态字符串/Node 数学测试不能替代 Android 触控、笔、缩放、键盘、窄屏和低性能设备测试；每轮交付附真实截图或录屏及移动端记录。
6. **生产安全**：公开仓库/静态部署与私人教材材料要隔离；禁止未经核验自动产生原题标准答案，也不可因 CI green 宣称生产成功。

## 实施顺序与退出门槛
### P0：修复现有交互，不改变数学输出
- 本分支：在 07 合成自画模式中增加跟笔预览与取消清理；仅 `workbench/**`、`tests/workbench/**`，未改数学引擎或发布配置。
- 修正性能瓶颈前先测量 DOM 重绘耗时、切帧延迟、3D 帧率和内存。
- 07 新行为测试至少覆盖：跟笔/抬笔/取消、短笔画、输入改变、模式切换、撤销重做；所有题型确保不泄露未验证答案。

### P1：提炼纯数据的统一步骤时间线（07 + 01/09 审核）
- 输入：已验 `Problem`、`Geometry`、`SolveResult`、`ConstructionStep` 与当前 input revision。
- 输出：每帧独立 action IDs、依赖、图层、验证状态、解释与 residual/DOF 的适用范围，非数学坐标重算。
- 仅当唯一解证明充分、或明确选择有效多解分支时渲染解步骤；无解/连续多解/不支持仅显示已知图和诊断。缺少 verified branch-step 映射时不得自动推进。
- 回归：随机步进与逐步播放产生完全相同的图元集合，回退移除未来图元；输入修改后旧 revision 一律拒绝。
- 第一批真实接入只做 **点投影与圆弧连接**，不得同时迁移所有教材示例。

### P2：教学视觉引擎
- 纸面左图右解保持现有配色、同纸 V/H/W、45°线；解释与按钮在右侧，手机单列；支持手动单步/暂停/逐帧/速度、辅助线开关和 reduced-motion。
- 区分已知绿、辅助橙虚、结果蓝、用户笔画单独层；逐线过渡对坐标无副作用。
- 点击线/点显示本步“为什么画它”、约束来源、剩余自由度的适用域、数值验算依据；不能把局部 Jacobian 自由度说成全局唯一。

### P3：继续扩展 04 截交线、05 相贯线、06 组合体及 08 AI 识图
- 以前置真实几何/遮挡测试通过为条件，优先做确定性三维模型和两视图一致性；不确定的第三视图保留多候选而不猜唯一。
- 教材原题只能经过实际原图核验和授权的私有访问路径进入播放系统；不把示意 SVG 当像素级复刻。

## 是否需要整体重构
- **不需要：** 网站布局、已经验证的点投影求解器、圆弧求解器、静态发布体系；大改风险高且收益小。
- **需要局部重构：** 时间线/图元状态/渲染适配层；这一部分已被多个页面重复实现，是后续复杂题型可维护性的决定性瓶颈。
- **现阶段继续搭建：** P0 稳定性修复、P1 两道真实数学题闭环和测试基础；P1 经验证前暂停向生产教学播放器叠加更多互不兼容的动画代码。
