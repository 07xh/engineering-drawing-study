# DraftAI V4 逐线动画与联动教学｜独立原型

## 本轮真实交付

本独立分支新增 `workbench/teaching-motion-v4.js` 和 `tests/workbench/teaching-motion-v4.test.cjs`。
它们是**纯表现层辅助函数**，既不生成工程制图数学答案，也不修改已有求解器、教材审核数据、前台入口和 Cloudflare 构建。

V4 本地交互演示已具备：
- 由线段起点渐进画至终点、圆规辅助圆逐周显现及运动笔尖；
- 图纸中点选辅助线，跳转对应作图步骤；鼠标移至步骤项可强调该步骤的图元；
- 可开关的自动聚焦（平滑 SVG viewBox）与黑白纸面模式；
- 响应式左右工作台、进度/速度/暂停、圆弧候选切换；
- 尊重 `prefers-reduced-motion`：减少相机插值与笔尖动效；降低动画移动强度。

浏览器演示只是**预览素材**，采用内置明确的示例数据，不是教材原题复刻或接入已核验的真实作图业务页面。

## 责任边界和复用要求

1. 01/02/03 的求解器负责模型坐标、约束、候选解、多解与残差；**07 不得使用动画插值反算几何结论**。
2. 07 的 `drawLine/drawCircle/drawArc` 接受完成了 **model → sheet** 映射的屏幕图元，输出渐进绘制参数；这不是公共几何契约和校验器。
3. `focusViewport/easeViewport` 只更改 SVG 观察窗口，不能修改源几何点、单位或数学容差。
4. `drawingStepMap` 仅在步骤与图元的稳定 ID 上建立点击联动。复杂的 dependsOn、SolveResult、候选分支校验必须仍走已有真实 contract validator。
5. 正式播放器接入时必须遵守无解/多解/欠约束/未验证的展示门禁，图元高亮不能绕过数学验证。
6. 纸面模式只切换视觉线型/线宽，不能影响计算结果，黑白图纸必须区分已知、辅助、结果、学生笔迹。
7. V4 独立 HTML 设计演示由聊天附件交付；本 PR 仅保留可供正式重构复用的 **纯渲染函数与数值测试**，不将演示题当成公开课程题目。
